# Nakami

**書庫の中身を見てから、要るものだけ取り出す。**

[English](README.md)

Nakami は、Windows の 7-Zip File Manager のように使える、Mac の無料の圧縮・展開ツールです。
Mac では zip をダブルクリックすると、アーカイブユーティリティが中身を全部すぐに展開してしまいます。
Nakami は書庫を一覧で開くので、フォルダをたどったり、ファイルを見たりしてから、要るものだけを取り出せます。

## できること

- **フォルダのように書庫の中を見る**：名前・サイズ・日付の一覧。書庫の中のフォルダに入ったり、上に戻ったりできます
- **要るものだけ取り出す**：選んで ⌘E、または Finder へドラッグ
- **開く・見る**：ファイルをダブルクリックで開く、スペースキーで Quick Look
- **Finder の Quick Look**：Finder で書庫を選んでスペースキーを押すと、中のファイルの一覧が出ます
- **文字化けしない**：Windows で作った zip（ファイル名が Shift_JIS）を自動で見分けます。手で切り替えることもできます
- **パスワード付きの zip**：ZipCrypto と AES の両方
- **書庫を作る**（⌘N）：ファイルやフォルダをドロップして並べ、zip・7z・tar.gz・tar.xz で保存。
  Mac のゴミ（`.DS_Store`・`__MACOSX`・`._` で始まるもの）は入れません。
  zip ではファイル名の文字コード（UTF-8 か Shift_JIS）とパスワードを選べます
- **今ある書庫を編集する**：zip・7z・tar.gz・tar.xz に、ファイルを足す・外す・名前を変える。
  保存すると元の書庫はゴミ箱に入るので、元に戻せます
- **Finder の右クリックから圧縮**：ファイルを右クリック →「サービス」→「**Nakami で圧縮**」
- **日本語と英語**
- **ネットにつながりません**：Nakami はインターネットに接続せず、データを集めることもありません
- **キー操作の早見表**（⌘?）：Windows のキー操作と並べて見られます

### 対応する形式

| | 形式 |
| --- | --- |
| 開く・取り出す | zip、7z、rar、tar、tar.gz（tgz）、tar.bz2、tar.xz、gz、bz2、xz、lzh（lha）、cab、cpio、xar、Z |
| 作る・編集する | zip、7z、tar.gz、tar.xz |
| パスワード | zip だけ（パスワード付きの 7z・rar は、一覧は見られますが取り出せません） |

## 動作環境

- Apple シリコンの Mac（M1 以降など。Intel の Mac では動きません）
- macOS 27.2 以降

どちらも、アップルメニュー →「この Mac について」で確かめられます（「チップ」の欄が Apple のものなら Apple シリコン、「プロセッサ」の欄に Intel とあれば Intel の Mac です）。

## インストール方法

1. [最新のリリース](https://github.com/synchrium/Nakami/releases/latest)から `Nakami-x.y.zip` をダウンロードします。
2. zip をダブルクリックして、`Nakami.app` を取り出します。
3. **Finder で `Nakami.app` を「アプリケーション」フォルダへドラッグします。**
   （必ず Finder で動かしてください。動かさずに開くと、macOS が一時的な場所から起動します）

### 初めて開くとき

Nakami は無料で、Apple の公証を受けていません（公証には有料の Apple Developer Program が要ります）。
そのため、初めて開くときに macOS が確認を求めます。

1. 「アプリケーション」の Nakami をダブルクリックすると、**「"Nakami"は開いていません」**と出ます。**「完了」**を押します。
   （「ゴミ箱に入れる」は押さないでください）
2. **システム設定 →「プライバシーとセキュリティ」**を開き、下の**「セキュリティ」**までスクロールします。
3. **「お使いの Mac を保護するために"Nakami"がブロックされました。」**の横の**「このまま開く」**を押します。
4. もう一度**「このまま開く」**を押し、パスワードを入れます（Touch ID でも大丈夫です）。

これで、次からはふつうに開けます。

<details>
<summary>ターミナルを使う方法</summary>

ターミナルに慣れている人は、このコマンドで上の手順と同じことができます。

```sh
xattr -dr com.apple.quarantine /Applications/Nakami.app
```

### 新しいバージョンにするとき

「アプリケーション」の `Nakami.app` を新しいものに置き換えます。
**macOS は新しいバージョンを別のアプリとして扱うので、[初めて開くとき](#初めて開くとき)の手順がもう一度要ります。**
「以前に使用していたバージョンと異なります」（今までの設定を使ってよいか）と聞かれたら、**「このまま開く」**を押してください。
置き換えたあと、Finder で初めてスペースキーを押したときに、Nakami の Quick Look についても同じことを聞かれることがあります。

## ダブルクリックで Nakami が開くようにする

**Nakami →「設定…」（⌘,）→「既定のアプリ」**で、使いたい種類をオンにするか、**「すべてオン」**を押します。
macOS が種類ごとに確認します。アプリが勝手に既定のアプリを変えられないようにする macOS の仕組みなので、まとめてはできません。

Finder でもできます。書庫を選んで「ファイル」→「情報を見る」（⌘I）→「このアプリケーションで開く」で Nakami を選び、「すべてを変更…」を押します。

## キー操作

| キー | すること |
| --- | --- |
| ⌘O | 書庫を開く |
| ⌘N | 新しい書庫を作る |
| ⌘E | 取り出す（何も選ばなければ全部） |
| Return・ダブルクリック | フォルダに入る・ファイルを開く |
| ⌘↑ か ⌫ | 上のフォルダへ |
| スペース | Quick Look |
| ⌥⌘A | 選択を解除 |
| ⌘? | キー操作の早見表（Windows のキーと並べて） |

新しい書庫の窓では、⇧⌘N で新しいフォルダ、⌘⌫ で書庫から外す（元のファイルは消えません）、⌘S で保存。

## ビルド手順

要 Xcode 27 以降

1. このリポジトリをクローンして、`Nakami.xcodeproj` を開きます。
2. 「Signing & Capabilities」で、Nakami と NakamiQuickLook のターゲットの Team を自分のものにします。
3. ⌘R で動きます。

リリースと同じもの（アドホック署名で、アプリに個人の情報が入らないもの）を作るには、次を実行します。

```sh
Scripts/build-dist.sh
```

Nakami は macOS に入っている [libarchive](https://www.libarchive.org/) を使います。
リポジトリには、そのヘッダーファイル 2 つだけを `CArchive/` に置いています。
